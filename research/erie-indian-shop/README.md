# Erie, PA — the 1920s–30s Indian motorcycle shop

Start with **[report.md](report.md)**.

- `report.md` — the answer, timeline, owner bio, photos, open questions, manual steps
- `erie_motorcycle_businesses_1920-1940.csv` — every Erie motorcycle/bicycle business found (1908–1947), with source URL, page/seq, the line as printed, and confidence
- `sources.md` — every source checked: hit / partial / miss / blocked
- `evidence/` — crops of the key pages (max 1800 px), named `YEAR_SOURCE_PAGE.png`
- `working-logs/` — each research lane's raw log (queries, results, reasoning), the access map and the critic's review
- `tools/` — the small helper scripts used (LOC OCR grep, LOC image fetch, Google Books feed, archive.org full-text search)
